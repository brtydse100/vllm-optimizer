# YAML reference

[**Open or download the complete YAML file**](full-example.yaml). It contains
every vLLM Optimizer-owned configuration field in one copyable file, with
comments for mutually exclusive modes and representative pass-through fields.

The `server`, `tune`, environment, and benchmark-backend mappings also accept
upstream fields, so their possible keys follow the installed vLLM, GuideLLM,
or vLLM Bench version. Use these focused references for the available forms:

- [Experiment, server, and tuning](full-example-server.md)
- [Benchmarks, optimization, and timeouts](full-example-benchmark.md)
- [Execution, logging, and optional summaries](full-example-execution.md)
- [vLLM Bench Serve alternative](full-example-vllm-bench.md)

Start with the [quick start](../../getting-started/index.md) when you do not need every option.
